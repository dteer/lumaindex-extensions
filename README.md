## 图文与视频发布

在有序图库内整理素材、文案和发布设置，由配套 Chrome 扩展直接带入抖音编辑页。App 插件和 Chrome 扩展的版本均为 **1.0.0**。上传完成后，用户在抖音核对并手动发布。

## 安装

1. 使用当前有序图库 App，并保持 App 运行。
2. 下载 [App 插件安装包](https://github.com/dteer/lumaindex-extensions/releases/download/douyin-v1.0.0/douyin-1.0.0.luma-plugin.zip)，在有序图库的“设置 → 插件 → 从文件导入”中安装。也可从 GitHub 安装，输入 `https://github.com/dteer/lumaindex-extensions`。
3. 下载 [Chrome 扩展安装包](https://github.com/dteer/lumaindex-extensions/releases/download/douyin-v1.0.0/douyin-chrome-extension.zip) 并解压。Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，指定包含 `manifest.json` 的目录。
4. 已加载本地扩展时，将目录更新为本次文件后点击扩展的重新加载。确认 App 插件与 Chrome 扩展均显示 1.0.0，并在 Chrome 登录抖音创作者中心。

本地构建目录中的 `抖音发布助手.luma-plugin.zip` 与 `Chrome扩展/` 可按相同步骤安装。

## 编辑与带入

- 在来源或集合中选择素材，通过素材菜单或顶部插件菜单带入“抖音发布助手”。
- 图文模式支持拖动排序、移除素材及还原本次带入素材。单击缩略图切换预览，双击查看大图；预览支持滚轮和方向键切图。
- 在 App 填写标题、描述及话题文本，选择可见范围、保存权限和发布时间。话题关联、好友、配乐及位置以抖音编辑页为准。
- 点击“带入抖音编辑页”后直接进入抖音对应编辑页，无需在中转页面再次操作。同一 App 草稿再次带入时复用其关联编辑页，不要求关闭其他抖音标签页。
- App 右侧的手机式预览仅供参考，不代表真实账号、上传状态或发布结果。
- 视频模式每次准备一个 MP4、MOV 或 WebM；插件不转码、不剪辑，无法播放的编码需先转换。

## AI 文案与图片分析

- 点击顶部“AI 文案”打开弹窗，主页面保留 2026-11-10 09:25 提交的基础信息、发布设置和作品预览布局。
- 提示词内置默认模板，可修改、保存并恢复默认；作品信息与提示词随当前图库的插件状态保存。
- 通过图库后端的 AI 连接生成标题和描述，先预览再应用；替换现有文案需确认，生成失败保留原文案，支持取消。
- “结合图片分析”默认关闭。开启后默认选首张可用图片，可在缩略图右下角勾选，最多 6 张；插件只提交素材 ID，后端读取已登记缩略图并转换为最长边 400 像素的 JPEG，再发送至 AI 服务。
- 缩略图不可用时不会回退读取原图。视频当前仅使用文字信息。图片分析会增加用量和耗时，模型需支持图片输入。
- 需要包含 `/api/v1/ai/copy` 能力的新版有序图库 App；本次按要求保持 App 插件与 Chrome 扩展版本为 **1.0.0**，更新后请重新导入插件。

## 图片同步规则

每次主动带入以 App 当前图片数量和顺序为完整快照：

- 复用素材身份、文件版本及抖音服务端资源均未变化的图片。
- 只上传新增、修改，以及网页已删除但 App 仍保留的图片。
- 移除 App 当前没有的网页图片，并按 App 顺序排列；排序不重新上传。
- 记录浏览器内的新增、删除、替换和排序，但不反向修改 App 草稿。导入前重新读取真实网页状态。
- 不凭同名或同大小认领素材，也不重新读取文件计算哈希。

图文文件通过二进制交接进入网页上传控件，不经过 Base64。成功上传的资源及时保存映射，后续文案或预览检查失败不会丢失已成功上传的资源。后台重启和等待超时不会立即重新投递仍在上传的文件；整批失败时按页面提示使用抖音的重新上传操作。

## 本地缩略图与上传进度

抖音当前首次整批入口要等整批上传完成才显示原生图片区。“继续添加”已有原生图片区，可以提前显示本地图片。

等待期间，扩展在独立的“带入图片”行显示本地缩略图和上传状态：有原生图片区时位于其前方，否则位于“封面设置”之后。临时区域不会插入作品描述框，也不会覆盖右侧预览。

临时缩略图直接使用同一份 File，由浏览器显示，不重复读取、编码或上传。原生图片区显示同批素材后自动收起。**左侧本地预览只表示已接收；服务端资源及右侧预览都确认后，才提示本次带入完成。**

## 发布设置

支持公开、好友可见或仅自己可见，允许或不允许保存，立即发布或定时发布。定时时间按本机时区输入，需在 2 小时后至 14 天内。扩展填写并回读发布设置，不会点击最终发布按钮。

## 暂存与关闭

- 每个图库独立保存插件状态，图文和视频各有一份草稿；记录素材 ID、顺序、文案及设置，不复制媒体文件。
- 编辑时保留恢复副本；“暂存”在本机保存成功后确认。保存失败会提示，并保留当前页面。
- 页面或宿主插件栏关闭、重新加载时，未暂存修改提供“暂存并关闭 / 不保留并关闭 / 取消”。“不保留”删除当前图库的图文和视频草稿；“删除草稿”只删除当前模式。
- 新素材遇到旧草稿时可选择覆盖或继续。继续会保留旧文案和顺序，按素材 ID 去重追加；覆盖只替换对应模式。
- 侧栏切换或退出 App 后可恢复已保存状态；强制退出时尚未完成的写入不保证保留。禁用或卸载插件不会主动清除草稿。
- 草稿是本机状态，不是抖音云端草稿。图库路径变化会视为另一份状态；来源离线或原文件移除可能导致无法预览、上传。

## 限制与验证范围

- 图文支持 1–35 张，单张不超过 50 MiB，总计不超过 80 MiB；视频单个不超过 80 MiB。这些是插件传输限制，不代表平台全部规则。
- JPEG、PNG、WebP 等适用原文件；RAW、HEIC 等使用图库已生成的 2048 浏览图，不直接上传 RAW。实况照片使用静态图片组件。浏览图缺失时会提示失败。
- App 和 Chrome 需保持运行。若 App 本机端口改变，从 App 再次带入即可，已有本机草稿保留。
- 网页结构无法确认时停止操作，保留明确错误提示。不要把“已交给网页”理解为上传完成或发布成功。
- 已实机核对 JPG 首次整批导入、重复导入复用、网页删图后单张补传、数量顺序和右侧预览；未点击发布。视频完整上传、真实 RAW 和实况照片的转换上传仍未实机验收。详细边界见 [验证记录](VALIDATION.md)。

## 开发与版本

`app/` 为 App 内嵌前端，`browser/` 为 MV3 扩展；运行只需 HTML、CSS 和 JavaScript，不需要 Python、Native Messaging 或额外桥接程序。

在仓库根目录执行：

```sh
node build.mjs /输出目录
for f in tests/*.mjs; do node "$f" || exit 1; done
```
