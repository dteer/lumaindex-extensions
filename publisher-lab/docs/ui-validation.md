# 当前发布页 UI 回归（2026-11-17）

当前交付是独立 App 插件，使用宿主原生登录、临时会话和受限请求能力。界面参考抖音创作者中心的上传页与图文编辑页，原浏览器扩展/relay 代码仅作历史参考，不进入 AppOnly 包。

## 已核对的界面与交互

- 顶部按“发布视频 / 发布图文 / 发布全景视频 / 发布文章”排列；后两项明确禁用。
- 空草稿展示规格说明和大素材选择区域。按钮跳到来源网格勾选并确认素材；单张图片 50 MiB、视频 80 MiB 的当前限制如实显示，不复制官方网页更高上传限额。
- 有素材后显示基础信息、扩展信息、发布设置三张白色卡片，右侧手机预览；小窗口单列。表单顺序为描述、封面、编辑图片、合集、自主声明、音乐、位置标签、关联热点、发布设置。关联热点可搜索、选择与清除；问号悬浮显示说明，移开隐藏。
- 可见范围、保存权限、立即/定时发布使用横向单选组，仍持久化原 settings 字段；定时输入显隐与本机保存已验证。
- 草稿由顶部轻入口打开抽屉。新建视频、返回原图文后，素材与标题完整保留。
- 点击“检查会话”不打开登录窗口；明确点击“登录抖音”才发送 `session.login{origin}`。登录成功后仍调用平台用户接口核对身份，并显示“重新登录”。取消登录保留原会话、账号和草稿。
- 话题查询、图库素材选择、保存草稿、清除会话通过。清除后平台操作禁用，本机内容保留。
- 1440×1000、820×850、560×850 无页面横向溢出，控制台无错误。底部操作位于表单末尾，不覆盖编辑字段。

## 测试范围

`tests/native-ui.mjs` 使用独立 bundled Chromium headless shell、本机静态 fixture、合成图库图片和明确的宿主接口模拟。它加载真实 UI/client/engine，没有读取用户 Chrome、没有使用用户素材、没有真实平台上传或发布。

`tests/native-transport.mjs` 覆盖原生分片、取消、显式登录和登录取消保留；`tests/native-cancellation.mjs` 覆盖查询取消及后续上传停止；`tests/native-engine.mjs` 与 `tests/native-publication-store.mjs` 覆盖账号核验、防重、unknown 恢复、过期准备清理和回执紧缩。

这些 UI 结果不代替官方网页登录窗口、真实网络和最终发布的实机验收。原生宿主构建与安装、临时文件接口的实机检查由宿主任务单独记录。历史预览占位版和浏览器执行模拟的描述已移除，避免与当前接线混淆。
