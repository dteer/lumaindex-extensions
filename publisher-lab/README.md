# 抖音发布工作台

独立的有序图库 App 插件，发布界面、业务编排、媒体协议和草稿均在插件内。它使用新版 App 的持久网页会话，在与登录相同的 WebKit 环境中完成平台查询和上传；**不需要 Chrome 扩展或单独服务。** 原「抖音发布助手」保持独立。

## 安装与账号登录

先使用已开放插件原生能力的新版有序图库，再从「设置 → 插件 → 从文件导入」安装：

`~/Desktop/app/抖音发布工作台/抖音发布工作台.luma-plugin.zip`

1. 打开「抖音发布工作台」，展开右上角账号菜单，点击「登录抖音」。
2. 在 **App 打开的官方登录窗口** 中扫码或完成短信验证，然后点击窗口下方的「完成登录」。插件页面不读取 Chrome、不接收 Cookie，也不把登录材料写入草稿、日志或发布记录。
3. 插件自动请求抖音账号接口核对身份；也可在账号菜单点击「检查会话」重新核对。以平台真实账号核验结果为准。
4. 登录使用稳定的账号网页环境，重开插件后可以继续复用。是否需要重新验证以平台实际状态为准；需要移除账号时在账号菜单点「移除当前账号」。

账号选择使用与编辑器一致的浅色下拉，列表与账号框对齐，支持方向键、回车和 Escape。支持保存多个账号：「添加账号」打开独立登录环境；已保存账号从下拉列表选择，打开工作台和切换档案不额外联网检查账号。「重新登录当前账号」复用所选账号原有的网页环境，核对一致后更新，不生成重复选项。新增时遇到已保存账号会提示选择原账号重新登录；取消或失败保留原档案和草稿。「移除当前账号」也会清理该账号的网页数据，其他账号与本机草稿保留。账号网页环境不会因为 App 的八小时原生快照期限而失效，平台仍可能要求重新验证。上传或提交进行中不能切换账号，切换后原有上传准备失效。

旧版 App 会明确显示需要更新，不能用连接成功或模拟账号伪装可用。

## 添加素材

编辑页保留基础信息、扩展信息与发布设置，正常编辑时右侧显示手机发布预览。打开 AI 助手后隐藏发布预览，关闭助手后恢复当前作品预览；左侧编辑作品，右侧依次展示可折叠的作品信息、图片分析和生成操作以及五项建议；两栏各自独立滚动，底部操作固定。收起作品信息保留生成状态，不清空输入、图片选择或中断生成。顶部错误提示可关闭，发布回执与折叠能力说明保留在编辑区域。草稿和账号入口仍位于顶部工具栏。

「本机草稿」列表每行都提供删除入口。确认后只删除本机草稿；图库素材、已提交作品和发布防重复记录保留。删除当前草稿后切换到其余草稿，删除最后一份后保留空白编辑入口。

点击「选择图库图片 / 视频」或「继续添加」，插件先保存当前草稿，再跳到 App 的来源网格。像添加集合一样勾选素材，点击确认后回到同一份作品；取消选择不会改动素材、封面或文案。

正文选择会排除已有素材，并按图片最多 35 张、视频 1 个限制剩余数量。图片可直接拖拽调整顺序，也可聚焦图片后按 Option + 左右方向键调整；排序自动保存并同步发布顺序，封面与当前查看焦点继续跟随同一图片。图片右上角的移除按钮只取消正文引用，不删除图库文件；如果该图片同时用作封面，封面和裁剪仍保留。

图文封面可以使用正文图片，也可以单独选择图库中的另一张图片。「选择图片」会展示当前作品图片，并提供「从图库选择」入口；没有正文图片时直接打开图库。选择封面不会把它加入正文，不占正文图片名额，也不改变发布顺序。取消选择保留原封面。封面可单独裁剪；当前裁剪器按正文首图确定比例，需要先添加正文图片。准备时会核对封面的类型和文件版本，再单独读取、裁剪或上传；正文内未裁剪的封面直接复用正文图片资源。

上传或发布进行中不能修改素材。进入来源选图需要宿主 `mediaSelectionVersion=1`；旧宿主会提示更新，不回退到插件搜索列表即点即加。

## 当前接入范围与验证边界

切换账号时，已选普通话题、@ 用户、地点和热点继续保留。话题和 @ 用户使用已保存的平台 ID，准备发布时不再按名称重新搜索；热点沿用已选词。城市筛选也不会因换号清空。地点可以复用公共的城市、关键词线索，但发布所需附加字段和额外确认要求仍从当前账号的查询结果取得，不复用其他账号的资格信息。

已完成的 AI 文案、地点和热点建议在同一作品、同一素材版本下可跨账号查看、编辑和应用；换号不自动重做整份建议。音乐音源和官方活动资格仍按各项生成时的账号检查，可分别点击“换一首 / 更换”更新；更新一项不会使另一项的旧账号来源生效。在途请求仍检查当前账号，旧请求的迟到结果不能替换当前建议。登录环境、上传缓存、准备快照和发布记录保持账号隔离。

- 图文/普通视频草稿、图片画廊与移除、拖拽排序、点击放大及左右滑动、标题与正文、独立图库封面与裁剪、可见范围、保存权限和定时设置。
- 正文 # 话题/@ 用户实时搜索与身份关联，选中标记显示淡蓝背景且不额外增加字符；无精确搜索结果的话题也能按名称选择，沿用官网的 0 标记，保存后仍保留关联；上传图片后获取平台推荐话题。
- “@ 好友”空关键词时显示最近联系人，输入昵称后显示搜索结果；列表展示头像、昵称、真实粉丝数与抖音号，高度受限并可在内部滚动。缺失资料不补造，选中后仍只保存用户 ID 与昵称。
- 图文和视频均可搜索并关联平台返回的热点词，支持清除；选择不会改变正文话题。首次点开读取平台当前热点，展示封面、热点词与在看热度；同账号同作品的默认列表缓存 5 分钟，重开立即显示，过期先显示已有列表并后台更新，也可点击「刷新」主动更新。输入关键词后搜索，清空后恢复默认列表；换账号、换稿、素材变化或完成新的上传准备后失效。图文已有完整上传快照时附带图片推荐线索，未上传也能查看全部热点；视频沿用平台默认推荐。草稿保存热点词，发布时提交 `hot_sentence`，是否关联生效以平台处理为准。
- 官方活动展示真实名称、热度和详情，可点击“刷新”重新获取列表；刷新失败保留已有列表和选择，不增加定时刷新。添加后同步对应话题，取消活动保留普通话题，删除正文话题会解除活动关联。普通话题与活动话题合计最多 5 个，准备时重新校验活动身份与可用状态。
- 图文音乐按平台真实目录展示推荐、热门榜、收藏、飙升榜、原创榜等分类，支持分类分页、关键词搜索、行内试听和底部播放器。已选音乐按 ID 核验，名称变化仍视为原配乐；点击「使用」只保存已查询候选，不额外联网检查账号，已保存的草稿也不重复写入；有未保存修改时先落盘，再把真实音源和时长按账号写入独立选曲记录。按钮显示保存进度，失败保留原配乐并提示处理。浏览、翻页不会淘汰已选记录，重新打开后可点击音符或「试听」直接使用同账号已保存的音源，不先请求音乐详情。试听缺少音源或播放失败后重试时，最多读取当前账号的推荐和收藏各两页查找同一 ID；找不到时保留原配乐并提示重新选择，不按名称替换歌曲。歌曲下架或播放地址失效时，不能保证继续试听。准备上传前用当前账号核对一次音乐 ID；时长属于歌曲资料，可按相同 ID 复用已保存的真实时长，不再扫描推荐或收藏。试听地址、登录会话和上传记录仍按账号隔离；没有真实时长时明确提示重新选择原歌曲。本次准备复用核验结果，上传后只刷新合集等会变化的信息。候选不会因为浏览超过 200 首或停留超过 30 分钟而拒绝选择，切换账号仍清理旧候选。
- 音乐分类目录按账号短期缓存，清空搜索回到所选分类。地点先选城市再搜索，城市下拉限制高度；合集下拉展示封面和作品数，按账号缓存分页，重复打开复用已读取页面。
- 合集作品需公开可见：选合集会扩大可见范围、或更改可见范围会移除合集时，先明确确认；已存草稿中的冲突在设置处提供解决按钮，不自动改成公开。问号说明在鼠标悬停时显示，移开隐藏；键盘聚焦可查看，失焦或 Escape 关闭。
- 普通查询直接调用所需接口，不额外请求账号信息；上传准备开始与真正发布前各保留一次实时账号核验。账号离线仅提示错误，保留账号名称、草稿、已选资源和 AI 文案，本地编辑与清除仍可用。普通查询不阻止换账号，发布状态查询不锁住编辑器。
- AI 助手保留作品背景和自定义提示词；拍照日期优先取正文首图 EXIF 原始拍摄时间，按照片记录的日期保留，不换算成本机时区；缺失时才从首图目录解析完整年月日，修图目录只回退到直接上一层。目录线索也使用这一层名称。文案首行固定为 `#有序图库` 并去重，只有有效日期才在末尾添加 `#YYYYMMDD`，应用文案时同时绑定并高亮品牌和日期话题，不额外查询话题或账号；没有依据时留空，不使用文件创建、修改或导出时间，也不猜今天。旧默认提示词会精确升级，自定义内容不覆盖；可显式选择最多 6 张缩略图分析。图文提供作品描述、官方活动、音乐、地理位置和热点五项建议。平台候选查询与活动话题解析均在插件内完成，App 只提供通用 AI 候选选择能力。活动或热点不相关时可建议“不参加 / 不关联”；失败与明确不关联分别展示。已有手选资源默认不勾选，应用所选一次写入，不重复确认或查询账号；未勾选活动的关联和正文话题会保留，明确取消活动则移除其话题。单项重新生成只更新对应建议，失败只重试失败项，关闭助手保留当前草稿的已完成结果。音乐与热点的铅笔图标紧邻“换一首 / 更换”，弹窗保存本项提示词只更新当前草稿，不发请求；再次推荐才使用，留空恢复顶部统一要求。提示词不进入发布快照，也不影响素材准备的有效性。
- 插件使用与登录相同的浏览器环境执行媒体上传、视频转码查询、发布准备、二次确认提交和作品记录查询。浏览器跨域限制正常生效，失败会如实提示。
- 图片单张暂限 50 MiB、最多 35 张；视频暂限 80 MiB。宿主上传缓存按 256 KiB 分片写入，不把完整媒体转成一个巨大 JSON。

用户已确认工作台可用，正式名称为「抖音发布工作台」。自动化回归覆盖编辑、账号隔离、媒体准备与发布状态流转；实际发布结果以平台回执为准。

全景、文章、视频配乐、视频地点/合集、需附来源或拍摄地点日期的声明类型、视频帧封面和定时合集组合尚未完整接入，界面明确标记或在准备前拒绝，不列为已支持能力。普通自主声明首次从平台读取，按当前账号和作品类型在页面内缓存，准备时再次实时核验；“内容为转载信息”不出现在可选列表。

AI 使用图库设置中的连接，图片分析默认关闭；启用后仅发送用户勾选素材的缩略图，不读原图。平台资源建议需当前抖音账号；未登录时仍可生成文案和搜索线索。模型结果、平台资源查找和界面应用已通过离线回归，实际模型质量取决于配置的 AI 服务。

## 发布确认与结果

准备成功后，还需核对账号与作品并明确确认。发布状态和请求身份由宿主独立持久化；写入失败时不发送发布请求。同一准备记录即使换请求编号也不会再次提交，重开后的未知结果不会自动重发。

目前接收到有效作品编号只显示「处理中」，不猜测平台审核状态。提交超时、断线或缺少完整回执显示「结果待确认」，应先查询并核对创作者中心。

## 文件与职责

本子项目位于 `lumaindex-extensions/publisher-lab/`，与仓库根目录的原发布助手保持独立。默认测试与隔离检查只覆盖实际交付的 App 实现和依赖闭包，不依赖原插件或历史浏览器目录。

`app/platform/` 是实际交付的发布协议和业务编排，`app/native-transport.js` 适配宿主消息。宿主只提供通用能力，不硬编码抖音发布业务。`browser/` 和 `docs/legacy-chrome-client.js` 仅保留早期研究参考，不进入安装包。历史协议、浏览器 worker 与原插件基准检查单独放在 `npm run test:reference`，不作为当前 App 的构建或发布前置条件。

```sh
npm test
npm run build
```

构建仅生成上述 App 插件 ZIP、说明和独立产物标识。不会安装浏览器扩展、自动登录或发布作品。构建产物和运行存储均使用独立插件 ID `com.lumaindex.douyin.studio`。

旧版独立话题/好友关联在草稿 v1→v2 升级时一次迁入正文，已有完整标记不重复添加；随后删除正文标记会同步解除关联。原图片顺序和其他草稿字段保持。
