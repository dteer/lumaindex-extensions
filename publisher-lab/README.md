# 抖音发布工作台（实验版）

独立的有序图库 App 插件，发布界面、业务编排、媒体协议和草稿均在插件内。它使用新版 App 开放的受限会话、网络请求和持久化接口；**不需要 Chrome 扩展，不启动单独服务，不控制浏览器页面。** 原「抖音发布助手」保持独立。

## 安装与临时会话

先使用已开放插件原生能力的新版有序图库，再从「设置 → 插件 → 从文件导入」安装：

`~/Desktop/app/抖音发布工作台实验版/抖音发布工作台实验版.luma-plugin.zip`

1. 打开「抖音发布工作台（实验版）」，展开右上角账号菜单，点击「登录抖音」。
2. 在 **App 打开的官方登录窗口** 中扫码或完成短信验证，然后点击窗口下方的「完成登录」。插件页面不读取 Chrome、不接收 Cookie，也不把登录材料写入草稿、日志或发布记录。
3. 插件自动请求抖音账号接口核对身份；也可在账号菜单点击「检查会话」重新核对。以平台真实账号核验结果为准。
4. 临时会话由宿主管理，具有有效期；需要移除账号时在账号菜单点「移除当前账号」。重开插件是否可以继续使用，以宿主会话状态和平台实际验证为准。

支持保存多个账号：右上角账号菜单中的「添加账号」打开独立登录窗口；登录过的账号可从「已登录账号」下拉选择，切换后会重新核对平台身份。同一账号再次登录只更新该账号会话，不生成重复选项。「移除当前账号」只移除当前项，其他账号与本机草稿保留。账号名称在会话到期后仍保留，显示「需重新登录」；登录有效期仍由宿主管理，最多 8 小时。上传或提交进行中不能切换账号，切换后原有上传准备失效。

旧版 App 会明确显示需要更新，不能用连接成功或模拟账号伪装可用。

## 添加素材

编辑页参照抖音创作者中心的图文发布页排列：基础信息、扩展信息、发布设置与右侧预览。草稿入口和账号操作位于上方工具行；实验能力说明位于折叠区，不使用常驻成功横幅占用编辑空间。

点击「选择图库图片 / 视频」或「继续添加」，插件先保存当前草稿，再跳到 App 的来源网格。像添加集合一样勾选素材，点击确认后回到同一份作品；取消选择不会改动素材、封面或文案。

正文选择会排除已有素材，并按图片最多 35 张、视频 1 个限制剩余数量。图片可直接拖拽调整顺序，也可聚焦图片后按 Option + 左右方向键调整；排序自动保存，并同步手机预览、分段线和发布顺序，封面与当前预览继续跟随同一图片。图片右上角的移除按钮只取消当前作品引用，不删除图库文件；移除当前封面图片时同步清空封面与裁剪。图文的「选择图片」封面入口直接展示当前作品图片，使用右下角圆形勾选单选，确认后替换封面；点击缩略图可放大，取消不改封面。上传或发布进行中不能修改素材。进入来源选图需要宿主 `mediaSelectionVersion=1`；旧宿主会提示更新，不回退到插件搜索列表即点即加。

## 当前接入范围与验证边界

- 图文/普通视频草稿、图片画廊与移除、拖拽排序、点击放大及左右滑动、抖音样式手机预览、标题与正文、当前图片封面与裁剪、可见范围、保存权限和定时设置。
- 正文 # 话题/@ 用户实时搜索与身份关联，选中标记显示淡蓝背景且不额外增加字符；上传图片后获取平台推荐话题。
- 官方活动展示真实名称、热度和详情；添加后同步对应话题，取消活动保留普通话题，删除正文话题会解除活动关联。普通话题与活动话题合计最多 5 个，准备时重新校验活动身份与可用状态。
- 图文音乐按平台真实目录展示推荐、热门榜、收藏、飙升榜、原创榜等分类，支持横向切换、分类分页、关键词搜索、行内试听和底部播放器；重新打开草稿后，已选音乐可点击音符或「试听」播放，按当前账号和同一歌曲身份重新获取试听地址，不保存短期音频地址。分类目录按账号短期缓存，清空搜索回到所选分类。先城市后地点，城市下拉支持搜索并限制高度；合集下拉展示封面和作品数，按账号缓存分页，搜索与重复打开复用已读取页面。
- 查询复用近期账号核验和宿主网络连接，准备与发布保持实时核验。
- AI 助手保留原助手的作品背景、自定义提示词、首图目录线索和日期标签；可显式选择最多 6 张缩略图分析。图文建议包括标题、描述、位置和背景音乐：先分析图片与背景，再查询抖音真实候选并匹配；位置依据不足时不绑定地点，音乐可试听。已有手选位置与音乐默认保留，用户勾选后才替换。查询或匹配失败仍保留文案，重试资源不会重复生成文案。
- 插件使用宿主请求执行媒体上传、视频转码查询、发布准备、二次确认提交和作品记录查询。
- 图片单张暂限 50 MiB、最多 35 张；视频暂限 80 MiB。宿主上传缓存按 256 KiB 分片写入，不把完整媒体转成一个巨大 JSON。

**这些执行路径已经完成离线回归，但最终真实上传和发布还未完成实机验收。** 平台发布可能要求额外验证、签名或账号配置；实验版不会移植安全 SDK 或绕过平台校验。HTTP 200 或素材上传成功不表示作品已经发布。

全景、文章、视频配乐、视频地点/合集、需附来源或拍摄地点日期的声明类型、视频帧封面和定时合集组合尚未完整接入，界面明确标记或在准备前拒绝，不列为已支持能力。普通自主声明首次从平台读取，按当前账号和作品类型在页面内缓存，准备时再次实时核验；“内容为转载信息”不出现在可选列表。

AI 使用图库设置中的连接，图片分析默认关闭；启用后仅发送用户勾选素材的缩略图，不读原图。位置和音乐需当前抖音账号；未登录时仍可生成文案和搜索线索。模型结果、平台资源查找和界面应用已通过离线回归，实际模型质量取决于配置的 AI 服务。

## 发布确认与结果

准备成功后，还需核对账号与作品并明确确认。发布状态和请求身份由宿主独立持久化；写入失败时不发送发布请求。同一准备记录即使换请求编号也不会再次提交，重开后的未知结果不会自动重发。

目前接收到有效作品编号只显示「处理中」，不猜测平台审核状态。提交超时、断线或缺少完整回执显示「结果待确认」，应先查询并核对创作者中心。

## 文件与职责

本子项目位于 `lumaindex-extensions/publisher-lab/`，与仓库根目录的原发布助手保持独立。隔离测试同时核对根目录原插件文件的基准哈希。

`app/platform/` 是实际交付的发布协议和业务编排，`app/native-transport.js` 适配宿主消息。宿主只提供通用能力，不硬编码抖音发布业务。`browser/` 和 `docs/legacy-chrome-client.js` 仅保留早期研究参考，不进入安装包。

```sh
npm test
npm run build
```

构建仅生成上述 App 插件 ZIP、说明和独立产物标识。不会安装浏览器扩展、自动登录或发布作品。构建产物和运行存储均使用独立插件 ID `com.lumaindex.douyin.studio`。

旧版独立话题/好友关联在草稿 v1→v2 升级时一次迁入正文，已有完整标记不重复添加；随后删除正文标记会同步解除关联。原图片顺序和其他草稿字段保持。
